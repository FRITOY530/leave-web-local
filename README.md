# 本地学生请假网页复刻

React + TypeScript + Vite 实现的本地页面，按 2026-10-26 浏览器参考复刻请假记录首页与详情。手机号、地址、证明附件及审核人使用示例数据。

## 本地预览

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4175
```

打开 `http://127.0.0.1:4175/`。在线访问地址：<https://fritoy530.github.io/leave-web-local/>。

## 页面和交互

- 首页显示“已通过”和“已销假”两条示例记录，点击进入对应详情。
- 详情还原字段布局、附件缩略图、文件名截断和六步审核流程。
- “已销假”详情显示顶部状态；“已通过”详情显示底部“定位销假”。
- 证明材料和家长知情同意附件支持本地预览、关闭。
- 浏览器后退、前进和刷新保持当前路由；进入页面回到顶部。
- 存在“审核中”或“已通过”的记录时，点击 `+` 显示参考页面的提示。
- `#/new` 保留已有本地表单，校验必填项、手机号和起止时间，提交后保存为“已通过”，审核流程默认完成。

数据只保存在当前浏览器的 `localStorage`。本地页面不连接学校系统、不保存登录票据、不上传文件。“定位销假”点击后先确认，确认后才把记录改为“已销假”，不获取位置或改变学校记录。辅导员审核人固定为 `201620012-黄渊健`。已有本地记录不会因本次页面改动被清空；新浏览器环境首次打开时显示默认示例。

## 检查

```powershell
npm run lint
npm run build
npm run test:e2e
```

E2E 脚本覆盖首页布局、两种详情状态、提示框、附件预览、导航与滚动归零、表单校验与本地保存，并检查没有学校域名请求；其测试服务仍使用配置中的 4173 端口。本地已运行 lint、build 和 E2E，详细尺寸与验收范围见 [视觉核验记录](docs/visual-verification.md)。

视觉还原需在相同浏览器、缩放比例和视口下对照；本次参考侧栏视口为 413 × 751，尚未完成逐像素差异验证。
