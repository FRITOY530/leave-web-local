# 申请请假页面复刻设计

## 目标

将现有 `#/new` 本地申请表调整到参考页的移动端视觉结构，目标视口为约 411px 宽。页面保持本地模拟，不访问学校系统，也不提交真实申请。

## 视觉实现

- 页面背景使用浅灰色，字段行使用白色和浅灰分隔线。
- 标签列固定为约 111px，使手机号、日期和过夜字段保持单行或按参考页换行。
- 必填星号放在标签左侧；选择项和日期项显示“请选择”与右侧箭头。
- 证明材料使用 148px 方形相机占位框，提交按钮使用参考页青绿色和 44px 高度。
- 地址与过夜标签保留窄屏自动换行，证明材料区域使用参考页的左右内边距。

## 行为边界

- 选择器仍使用本地底部弹层。
- 日期输入仍由浏览器本地控件填写，但视觉层显示参考页文本。
- 文件选择只保存当前浏览器中的文件名，不上传文件。
- “提交”仅执行现有本地校验并写入 `localStorage`；本轮核验不点击参考页提交按钮。

## 验证

- `npm run lint`
- `npm run build`
- `npm run test:e2e`
- 使用 413×751 本地截图核对字段、证明材料和底部按钮布局。
