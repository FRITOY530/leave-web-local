# 本地学生请假网页复刻设计

## 目标

在 `C:\Users\15700\leave-web-local` 创建一个移动端优先的本地网页，复刻参考网站的学生请假记录与新建请假流程。它只模拟界面和本地数据，不连接学校系统，不保存或使用真实账号密码，也不提交真实请假申请。

## 范围

- 请假记录列表页：展示模拟学生信息、记录卡片、状态、日期、天数和“没有更多啦”。
- 右下角青绿色“+”按钮：打开新建请假页。
- 新建请假页：复刻请假性质、请假类型、请假天数、请假事由、证明材料、手机号、开始/结束时间、请假去向、具体地址、是否在校外过夜和提交按钮。
- 选择器使用本地弹层；日期使用本地日期/时间控件；证明材料只显示本地选中的文件名，不上传。
- 提交只做前端校验并写入 `localStorage`，随后返回列表页；数据没有任何外部副作用。
- 支持通过带确认框的“清空”操作删除当前浏览器中的本地模拟记录，便于验证空列表状态。

## 视觉方向

- 移动端 H5 优先，默认内容宽度为 100%，适配约 375–430px；桌面端居中显示窄屏模拟器。
- 背景为 `#f9f9f9`，表单单元格为白色，分割线为浅灰色。
- 字体优先 `PingFang SC`, `Microsoft YaHei`, sans-serif；正文约 16px，辅助文字约 14px。
- 主色为青绿色，沿用参考页的约 `rgb(82, 199, 202)`；必填星号使用红色。
- 复刻单元格左侧标签、右侧“请选择”和箭头、文本域高度、上传图片占位框、底部提交按钮和悬浮加号。

## 数据与安全

- 初始数据是脱敏的模拟数据，写在前端常量中。
- `localStorage` key 为 `leave-web-local-records`。
- 不调用参考站点接口，不把参考站点 ticket、账号、密码写入代码、日志或配置。
- 所有字段校验均在本地完成；手机号和地址仅作为演示值处理。

## 组件和数据流

- `App`：根据本地路由状态渲染记录页或新建页。
- `RecordListPage`：读取 records，展示列表和空状态。
- `LeaveFormPage`：维护表单状态，打开选择器/日期控件，校验并保存。
- `SelectSheet`：移动端底部选择弹层，点击选项后回填字段。
- `readRecords` / `saveRecords`：统一读写 localStorage，数据损坏时回退到初始模拟记录。
- 提交流程：表单状态 → `validateForm` → `storage.addRecord` → 返回记录列表。

## 验收标准

1. `npm run build` 成功。
2. 本地开发页可在记录页和新建页之间导航。
3. 新建一条完整模拟记录后，刷新页面记录仍存在；自动化测试覆盖该流程。
4. 未填写必填项时不保存，并在对应字段下显示错误。
5. 页面不产生网络请求到 `hnuit.edu.cn`，不含真实凭据。
6. 在约 390px 宽度下布局不出现横向滚动，关键控件可见且可操作。
